# TubeClone - YouTube Clone

A modern YouTube-like video streaming platform built with vanilla JavaScript, Express.js, and Node.js.

## Features

✅ Dark mode YouTube-style UI
✅ Video grid layout with thumbnails
✅ Search functionality
✅ Video player integration
✅ Responsive design
✅ Suggestions sidebar
✅ Mobile-friendly

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Server
```bash
npm start
```

### 3. Open in Browser
```
http://localhost:3000
```

## Project Structure

```
youtube-clone/
├── index.html       # Main frontend (single-page app)
├── server.js        # Express backend server
├── package.json     # Dependencies
└── README.md        # This file
```

## API Endpoints

- `GET /api/videos` - Get all videos
- `GET /api/videos/search?q=term` - Search videos
